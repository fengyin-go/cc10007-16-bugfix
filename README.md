# 数据分层建模工作台

离线版数仓分层建模工具，覆盖贴源层、明细层、汇总层、应用层的表结构设计、分区策略配置、质量规则编排与血缘关系管理，数据持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-layer-studio:entries` 这一项，或调用 `resetModule(模块)`。

## 转换编排：依赖封印链

转换编排（`transform`）在普通清单之外，额外有一套封印链运行态，实现集中在
`frontend/src/data/orchestration.ts`，独立持久化在 `data-layer-studio:orchestration`：

- **点火前置**：每个转换节点点火前必须持有全部输入表与前置节点的「当前有效签章」，缺一即断签，
  计划停在断签位置，点火被阻断并落一条 `blocked` 波次。失败策略只在波次失败后介入，不参与点火判断。
- **冻结 / 重签**：签章（输入表或节点）可冻结、可重签；重签后签章序号 +1，续跑只处理未完成波次，
  已完成波次锁定的历史签章证据永不重写。
- **相撞裁决 / 幂等**：每次封印与点火都占用单调递增的全局签章顺序 `sealOrder`，冻结与点火相撞时
  按顺序裁决（冻结在先则阻断）；同一幂等键只放飞一个实例，重复请求返回既有波次。
- **监控对账**：上游冻结会留下断签事件（`SealEvent`），任务监控页与概览按断签如实汇总异常，不再
  按绿态掩盖。节点详情页（`/transform/:id`）以转换编排为主对象回看每个执行波次的证据与审计。
- 领域规则有端到端测试：`cd frontend && npm test`。

## 对象生命周期与列表/详情口径

- 模块元数据的 `transitions` 登记每个动作允许发起的当前阶段白名单；`runAction` 据此校验，
  恢复、归档等动作与对象当前状态绑定，不能跨阶段跳转。
- 归档对象默认从列表页隐藏（可勾选「显示已归档」），但不删除；详情页始终从主存储按 id 实时读取，
  保证列表与详情值一致。通用详情页为 `src/views/generic/Detail.vue`，转换编排用专属波次回看页。
- 本地数据结构带版本号（`data-layer-studio:version`），种子口径升级时旧缓存自动迁移。
